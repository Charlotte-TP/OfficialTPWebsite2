Zapier Integration Guide

Follow these steps to connect TRUE Pulse with Zapier using a webhook.

Step 1: Log in to Zapier

  • Go to zapier.com and sign in to your account.
  • Click Create Zap.

Step 2: Create Webhook Trigger

  • Search for Webhooks by Zapier.
  • Select Catch Hook as the trigger event.

Step 3: Copy Webhook URL

  • Zapier will generate a webhook URL like:
  • https://hooks.zapier.com/hooks/catch/123456/abcxyz/
  • Copy this URL and paste it into TRUE Pulse Integration setup for which will specified in the following steps.

Step 4: Open Zapier Integration in TRUE Pulse

  • Log in to TRUE Pulse.
  • Go to Integrations → Zapier.
  • Click New Integration.

Step 5: Fill Integration Details

  • Select the Service / Business.
  • Paste your Zapier Webhook URL obtained by following the previous steps.
  • Choose push mode: Automatic, Manual, or Both.
  • Click Create to save the integration.

Important Notes

  • Each Zap requires a unique webhook URL.
  • Disabling the Zap will stop incoming data.
  • Deleting the integration in TRUE Pulse stops all webhook delivery.
